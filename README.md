# Employee-Attendance-System
A C++ employee attendance system that tracks working hours, lateness, and overtime.
## Features

- Employee name management
- Daily entry and exit time recording
- Late arrival tracking
- Overtime information
- Present and absent status detection
- Monthly attendance reports

## Tech Stack

- Language: C++
- Libraries: iostream, iomanip, string
- IDE: Visual Studio

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/arinamzl/Employee-Attendance-System.git
2. Open the project in Visual Studio.
3. Build and run the program.

## Usage

1. Enter employee names.
2. Input daily entry and exit times.
3. View the monthly attendance report.
4. Review attendance status, late arrivals, and overtime information.
